### API - библиотечный менеджер.

Модуль авторизации использует гибкую систему прав доступа для каждого endpoint.
При регистрации по умолчанию пользователю назначается право на чтение публичных разделов ресурса.
Пользователю доступны:
- регистрация
- авторизация
- просмотр регистрационных данных
- частичное изменение регистрационных данных
- ознакомление со списком хранящихся на руках книг (дата возврата, количество дней до возврата)

Управление книгами, авторами:
- добавление, удаление, изменение книг в каталоге
- пагинированный список всех книг
- удаление выбранных книг
- полное удаление каталога (суперпользователь)

Функции библиотеки:
- добавление книги в библиотеку в количестве Н экземпляров
- выдача, возврат
- просмотр всех выданных книг с пагинацией, просмотр выданных книг для пользователя

Администратор (Суперпользователь):
- просматривает список пользователей
- редактирует учетные данные пользователя
- обладает доступом к просмотру информации о состоянии приложения
- управляет состоянием каталога
- может блокировать пользователя за нарушение правил

Запуск приложения:
Пока не создан докер образ:
- клонируем репо на диск
- создаем сами в корне или запрашиваем у автора .env файл.
- uvicorn main:app --reload
- 127.0.0.1:8000/docs#/ подробная документация

Что полезного:
- протестирован модуль авторизации от tiangolo с использованием scopes
- что позволяет оперативно разворачивать проекты большего масштаба
